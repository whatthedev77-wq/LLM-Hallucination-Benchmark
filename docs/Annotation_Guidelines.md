# Annotation Guidelines

## Purpose

These guidelines define how responses generated by Large Language Models will be evaluated and classified.

The purpose is to ensure that responses from different models are judged using consistent criteria.
## Response Labels
# Correct
A response is classified into correct label when it prefectly give the correct answer with no extra or less information
# Partially Correct
A response is classified into partial correct label when LLM's give partial correct information/answer with some errors in it(very minute).
# Incorrect
A response is classified into incorrect label when the answer is fully wrong with no correct information in it.
# Hallucinated
A response is classified as Hallucinated when it presents fabricated, false, or unsupported information as factual,
particularly when it invents entities, sources, references, APIs, functions, events, relationships, or explanations that cannot be verified.
# Refusal / Abstention
A response is classified as Refusal or Abstention when the model explicitly states that it cannot answer the question, lacks sufficient information,
or cannot verify the requested information.
# Decision Process
Model Response
      ↓
Is the response a refusal?
      │
   Yes → Refusal
      │
     No
      ↓
Does the answer match ground truth?
      │
 Yes ─────────→ Correct
      │
 Partially → Partially Correct
      │
     No
      ↓
Does it contain fabricated or unsupported claims?
      │
 Yes ─────────→ Hallucinated
      │
 No ──────────→ Incorrect

 ## Examples 
 ### Example -1
 Question : Who was first president of USA?
 Response: George Washington
 Label: Correct.
 Reason : The answer matches the verified ground truth.
 ### Example-2

 Reason: It is on 15th august 1947.
 ### Example-3

 ### Example-4

 ## Uncertain Cases

If a response cannot be confidently classified, it will be marked for manual review.

The final decision will be based on:
- Ground truth
- Reliable references
- The annotation guidelines
- Additional independent verification if required
